
## App signup issues 

### 1 - Issue: Signup Form Validation Problem
The First Name and Last Name fields on the signup page return errors for invalid formatting if the user accidentally includes trailing spaces. The error 
message incorrectly suggests the issue is related to prohibited characters, such as dashes, which can confuse users who are unaware that the actual problem is the extra space.
#### Proposed Solution:
Update the field validation process to automatically trim trailing spaces before the submission is finalized. This adjustment will improve user experience by preventing unnecessary errors and reducing confusion during signup.
